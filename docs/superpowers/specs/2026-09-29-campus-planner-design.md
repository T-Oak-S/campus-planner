# 校园时间管理工具设计说明

## 目标

为东南大学大一学生提供一款可在手机和电脑使用的中文个人时间管理网页。应用统一展示按教学周变化的课程、个人活动和待办任务，提示时间冲突与空闲时段，并能把具体日期的安排导出到系统日历。

## 产品结构

应用采用四个一级入口：今日、日历、任务、设置。今日页聚合下一项安排、当日时间线、临近截止任务和空闲时段；日历页提供教学周周视图和月视图；任务页管理作业与截止日期；设置页管理作息、账户同步、日历导出与数据备份。

手机端使用底部导航，桌面端使用左侧导航。视觉风格采用温暖的纸张底色、蓝紫主色和珊瑚色强调，课程按稳定颜色区分。

## 时间与课程规则

- 第 1 教学周周一为 2026-09-21，教学周连续编号，假期不改变编号。
- 课程由多条规则组成，每条记录星期、开始/结束节次、周次集合、教师和地点。
- 中秋、国庆、校运会和考试复习期只停课程，不删除个人活动。
- 2026-09-20 按 2026-10-06 的星期和教学周规则补课；2026-10-10 按 2026-10-07 的规则补课。
- 单次课程可以覆盖为取消、调时、换教室或备注变化。
- 作息尚未配置时显示节次；配置后才参与精确时间冲突、空闲时段和课程日历导出。

## 数据与同步

前端采用 React、TypeScript 和 Vite。领域逻辑与界面分离，教学周展开、冲突检测、空闲计算和 ICS 生成均为可独立测试的纯函数。

Supabase 保存用户设置、活动、任务和课程覆盖，GitHub OAuth 用于登录。所有表启用行级安全并以 `user_id = auth.uid()` 隔离。未配置 Supabase 时应用进入本地演示模式，数据存入浏览器；配置后登录用户仍保留最近一次同步快照，离线时只读展示。

## 数据边界

- `CourseRule`：课程名称、教师、地点、星期、节次范围、适用周集合和颜色。
- `CourseOccurrence`：由规则和校历展开的具体日期课程，可叠加单次覆盖。
- `Activity`：单次或每周重复的个人安排，包含起止时间、地点和备注。
- `Task`：标题、截止时间、优先级、完成状态和可选关联课程。
- `PeriodSchedule`：1 至 13 节的可选起止时间。
- 云端记录包含 `updated_at`；远端与本地均在上次同步后修改时返回冲突，由用户选择版本。

## 可靠性与隐私

写入失败不清空表单并提供重试。导入文件先校验版本和字段，再替换数据。ICS 导出为当前安排快照，默认提前 15 分钟提醒。公开仓库只包含 Supabase 公共 URL 和匿名密钥的环境变量名称，不包含服务端密钥、截图或个人 OAuth 密钥。

## 验收

自动测试覆盖第 1、9、11、14、16 周，两个补课日、全部停课区间、活动冲突、空闲时段、重复活动、任务状态、备份恢复、ICS 日期与提醒。构建产物以 `/campus-planner/` 为基础路径，可由 GitHub Actions 发布到 GitHub Pages。
